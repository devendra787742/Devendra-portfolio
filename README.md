🚀 Run Locally

Follow these steps to run the portfolio on your computer.

1. Clone the repository

git clone https://github.com/YOUR_USERNAME/portfolio.git

2. Navigate to the project directory

cd portfolio

3. Open the website

Open index.html in your browser, or open the project in Visual Studio Code and use the Live Server extension for local development.

No build process is required for the current plain HTML, CSS, and JavaScript setup.

☁️ Deployment

This portfolio is deployed using Vercel and connected to GitHub for version control.

To deploy your own version:

Fork or clone the repository.

Import the repository into Vercel.

Select Other as the framework preset.

Leave the build command empty for the static website.

Deploy the project and access the generated public URL.

Subsequent pushes to the connected production branch can trigger automatic deployments.

🔄 Updating the Portfolio

After making changes locally, run:

git add .
git commit -m "Update portfolio"
git push

If the repository is connected to Vercel, your live website will update automatically after a successful deployment.
